## راهنمای نصب و راه‌اندازی (Setup Guide)

برای نصب و اجرای پروژه مراحل زیر را دنبال کنید:

1. کلون کردن مخزن:
   ```bash
   git clone <repository_url>
   ```

2. نصب پکیج‌ها:
   ```bash
   npm install
   ```

3. تنظیم متغیرهای محیطی در فایل `.env`.

4. اجرای دستورات Prisma برای همگام‌سازی دیتابیس.

5. اجرای پروژه در حالت توسعه.
